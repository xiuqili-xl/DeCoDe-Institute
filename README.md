# DeCoDe Institute

This repository contains my code, notes, outputs, and exploratory analyses from participating in the NIH Common Fund Data Ecosystem [DeCoDE Institute 2026](https://github.com/CFDETrainingCenter/decode-institute-2026). More information about the program is available from the [CFDE Training Center](https://www.orau.org/cfde-trainingcenter/training/decode-institute.html).


<br/>

## Repository Purpose and Structure

This repo is **a personal working space** for learning and exploration during the DeCoDE Institute. Some scripts are follow-alongs from the training material, with modifications and notes added as I worked through them. Other scripts are independent explorations or replications of public RNA-seq analyses. These scripts were *not* intended to be a polished or fully reproducible analysis workflow.

Files within the data, output, and graph directories are generally grouped by dataset or analysis:

- `code/` R scripts for training follow-alongs, dataset exploration, and independent analyses
- `code_markdown/` R Markdown training material and rendered notebooks. The main curriculum file is `06_R_Intro.Rmd`
- `data_raw/` Public datasets and metadata used as analysis inputs, organized by dataset
- `data_processed/` Intermediate or processed data objects saved for later analyses
- `outputs_csv/` Tabular outputs generated by data-wrangling and differential-expression analyses
- `outputs_rds/` Serialized R objects generated for reuse in later analysis steps
- `graphs/` Static and interactive figures, organized by dataset or analysis
- `galaxy/` Galaxy-generated Fastp and MultiQC reports saved for reference

<br/>


## Main analysis threads

### R and tidyverse follow-alongs

These scripts follow the DeCoDe R training curriculum, including:

- exploring the MoTrPAC rat endurance training data package
- working with phenotype and sample metadata
- using tidyverse tools for filtering, grouping, joining, pivoting, and plotting
- generating exploratory figures with `ggplot2`
- exploring normalized transcriptomic data and differential-analysis results

Relevant scripts include:

- `code/01-intro-R-tidyverse.R`
- `code/02-joining-pivot-plotting.R`
- `code/03-omics-bonus.R`


### DESeq2 and Galaxy replication

These scripts focus on understanding differential-expression workflows in R and comparing them with Galaxy-based analyses.

Topics include:

- preparing count matrices and sample metadata
- constructing and filtering DESeq2 datasets
- normalizing counts and performing differential-expression analysis
- generating MA plots, PCA plots, heatmaps, volcano plots, and sample-distance heatmaps
- reproducing analyses using public datasets

Relevant scripts include:

- `code/04-galaxy-DESeq2-rep.R`
- `code/05-gtex-data.R`
- `code/xx-DESeq2-tutorial.R`
- `code/xy-DESeq2-Carpentries_Main.R`
- `code/xy-DESeq2-Carpentries-GEO-reconstruction.R`



### MoTrPAC dataset exploration

These scripts explore MoTrPAC phenotype and transcriptomic data.

Topics include:

- exploring phenotype, training, body-composition, and VO2 measurements
- linking MoTrPAC sample identifiers to SRA and GEO records
- exploring raw counts, normalized expression data, and differential analysis outputs

Relevant scripts include:

- `code/01-intro-R-tidyverse.R`
- `code/02-joining-pivot-plotting.R`
- `code/03-omics-bonus.R`
- `code/11-liver-analysis.R`
